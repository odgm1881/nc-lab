# Примеры файлов для НК-ЛАБ

Готовые файлы номенклатуры для проверки импорта в кабинете (раздел **Импорт**).

| Файл | Что внутри |
|---|---|
| `номенклатура-пример.xlsx` | Excel: 11 строк — 9 корректных SKU футболки (3 цвета × 3 размера) с валидными GTIN и РД + 2 «проблемные» строки для демонстрации валидатора. |
| `номенклатура-пример.csv` | То же самое в CSV с разделителем `;` (как в выгрузке 1С). |

**Как проверить:** войдите в кабинет → **Импорт** → перетащите файл → «Создать карточки-черновики». Затем откройте **Каталог**, нажмите **Валидировать** на строках — 9 футболок пройдут проверку, 2 проблемные покажут ошибки (`GTIN_INVALID`, `ATTR_MISSING`, `RD_MISSING`).

Заголовки распознаются автоматически. Поддерживаемые колонки: Наименование, Артикул,
Категория, GTIN, Цвет, Размер, Пол, Состав, Возрастная группа, Бренд, Страна,
Тип РД, Номер РД, Дата РД, Срок действия. Регистр и порядок значения не имеют.

> GTIN в примерах — с корректной контрольной цифрой GS1 (сгенерированы доменным
> кодом проекта). Это тестовые номера, не привязанные к реальным товарам.

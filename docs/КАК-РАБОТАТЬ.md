# Как работать с НК-ЛАБ — руководство пользователя

Это пошаговая инструкция для клиента (импортёр одежды / селлер) и оператора.
Про то, «как всё устроено внутри и что реально работает» — отдельный документ
[`КАК-ЭТО-РАБОТАЕТ.md`](КАК-ЭТО-РАБОТАЕТ.md).

Готовые файлы для примеров лежат в папке [`samples/`](../samples/).

---

## 0. Вход в кабинет

Откройте кабинет (локально — http://localhost:5173 в дев-режиме или http://localhost:8080
в Docker) и войдите одним из демо-аккаунтов:

| Логин | Пароль | Роль |
|---|---|---|
| `client@nk-lab.ru` | `password` | Клиент (импортёр) |
| `operator@nk-lab.ru` | `password` | Оператор каталога |

Можно и зарегистрировать новую организацию на вкладке **Регистрация**.

**Роли:**
- **Клиент** — загружает номенклатуру, строит вариации, заполняет и валидирует карточки, публикует.
- **Оператор** — видит всё то же + раздел **Консоль оператора** (спорные карточки и очередь задач).

---

## 1. Обзор

Стартовая страница показывает состояние каталога:
- **Стат-тайлы** — сколько карточек всего, черновиков, с ошибками, валидных и готовых к публикации. Клик по тайлу открывает каталог с этим фильтром.
- **Конвейер готовности** — процент карточек, доведённых до «Валидна»/«Готова к публикации», и разбивка по статусам.
- **С чего начать** — быстрые ссылки на импорт, вариации и каталог.

Цель работы: провести карточки по цепочке **черновик → валидна → готова к публикации** до заказа кодов маркировки.

---

## 2. Сценарий A. Импорт номенклатуры из файла

1. Меню → **Импорт**.
2. Перетащите файл `samples/номенклатура-пример.xlsx` (или свой Excel/CSV) в область загрузки.
3. Появится **предпросмотр**: система распознала строки, разложила цвет/размер/пол в атрибуты, тип РД — в структуру. Файл ещё **не сохранён**.
4. Нажмите **«Создать карточки-черновики»**. Из 11 строк примера создадутся 11 карточек, и они **сразу автоматически валидируются** — статус (Валидна / Ошибки) проставляется без ручного клика.
5. Откроется **Каталог**: 9 футболок будут «Валидна», 2 проблемные строки — «Ошибки» с конкретными замечаниями.

Заголовки колонок распознаются автоматически по синонимам (Наименование/Название/Модель,
Артикул/Код/SKU, Категория/ТН ВЭД, GTIN/Штрихкод/EAN и т.д.). Регистр и порядок не важны.

> Если в файле у двух строк одинаковый GTIN, второй сбрасывается в пустой — правило
> «1 GTIN = 1 карточка» не нарушается, а GTIN потом проставит оператор.

---

## 3. Сценарий B. Построение вариаций из модели

Когда есть одна модель во многих цветах и размерах, не нужно вбивать каждую карточку руками.

1. Меню → **Вариации**.
2. Заполните: наименование модели, базовый артикул, категорию (например `6109`), общие атрибуты (вид изделия, состав, возрастная группа).
3. Введите оси через запятую: **Цвета** `чёрный, белый, синий`, **Размеры** `S, M, L`, **Пол** `мужской`.
4. **Предпросмотр** покажет, сколько SKU получится (3 × 3 = 9) и их артикулы.
5. **Создать карточки** — каждая комбинация станет отдельной карточкой-черновиком.

Так реализовано правило легпрома: **цвет и размер — отдельные вариации**, а не «оттенки» одной записи.

---

## 4. Работа с каталогом

Меню → **Каталог**. Два режима:

- **Модели** (по умолчанию) — карточки **сгруппированы по товару-модели**. Если вы загрузили
  таблицу с «Футболкой X» и «Свитером X», это будут две отдельные строки-модели со своей
  разбивкой статусов (сколько валидных / с ошибками / черновиков), а не свалка в один список.
  Клик по модели → «Открыть» → покажет только её вариации.
- **Все карточки** — плоский список с фильтром по статусу (Все / Валидны / Ошибки / Черновики /
  Готовы к публикации) и поиском по наименованию, артикулу, GTIN. Клик по строке открывает карточку.

Меньше ручной работы:
- **Автовалидация** — после импорта и построения вариаций карточки уже провалидированы, статусы проставлены сразу.
- Кнопка **«Провалидировать всё»** в шапке — одним нажатием прогоняет все неопубликованные карточки (например, после массового редактирования).

---

## 5. Карточка: заполнение, валидация, готовность к публикации

Откройте карточку (например, проблемную «Куртка деми» из примера).

1. **Заполните поля:**
   - Наименование, артикул, категория (ТН ВЭД).
   - **GTIN** — 8/12/13/14 цифр с корректной контрольной цифрой. Необратим: проверяется до заказа кодов.
   - **Атрибуты категории**: вид изделия, состав сырья, размер, цвет, пол, возрастная группа (обязательные для одежды).
   - **РД**: тип (декларация / сертификат / отказное письмо), номер, дата, срок действия.
2. Нажмите **«Сохранить и валидировать»**.
3. Справа в панели **«Результат валидации»** появятся замечания с машиночитаемым кодом:
   - `ATTR_MISSING` — не заполнен обязательный атрибут;
   - `GTIN_MISSING` / `GTIN_INVALID` — нет GTIN или неверный формат/контрольная цифра;
   - `GTIN_NOT_UNIQUE` — GTIN уже у другой карточки;
   - `VARIATION_MIXED` — в цвете/размере смешаны несколько значений;
   - `RD_MISSING` / `RD_FIELD_MISSING` / `RD_EXPIRED` — проблема с разрешительной документацией.
4. Исправьте поля, снова «Сохранить и валидировать». Когда ошибок нет — статус станет **«Валидна»**.
5. Кнопка **«Готово к публикации»** станет активной и переведёт карточку во внутренний статус **«Готова к публикации»**.
6. Кнопка **«Скачать пакет НК»** сформирует версионированный JSON-файл и запишет операцию в журнал обмена. Это файловый режим: во внешнюю систему данные автоматически не отправляются.

> Важно: любое редактирование сбрасывает карточку обратно в «Черновик» — это заставляет перепроверить её перед подтверждением готовности.

---

## 6. Консоль оператора (роль «Оператор»)

Меню → **Консоль оператора** (виден под `operator@nk-lab.ru`):
- Вкладка **«Карточки с ошибками»** — все карточки в статусе «Ошибки» с кодами замечаний. Клик открывает карточку для правки.
- Вкладка **«Задачи»** — очередь задач по спорным карточкам: «В работу» → «Решено», с приоритетом.

---

## 7. Полный демо-маршрут за 2 минуты

1. Войдите как `client@nk-lab.ru`.
2. **Импорт** → загрузите `samples/номенклатура-пример.xlsx` → «Создать карточки».
3. **Каталог** → отфильтруйте по «Черновики» → откройте «Футболка PREMIUM …» → «Сохранить и валидировать» → станет «Валидна» → «Готово к публикации».
4. Откройте «Куртка деми» → «Сохранить и валидировать» → увидите ошибки → добавьте состав/пол/возрастную группу, исправьте GTIN, заполните РД → снова валидируйте → «Валидна».
5. Войдите как `operator@nk-lab.ru` → **Консоль оператора** → посмотрите карточки с ошибками.

---

## 8. Частые вопросы

**Почему после импорта у части карточек нет GTIN?** В примере это специально: строки без GTIN
(или с дублем) остаются черновиками — GTIN проставляется вручную до заказа кодов.

**Можно ли отметить готовой карточку с ошибками?** Нет. Действие доступно только для статуса «Валидна».

**Что значит «Готово к публикации» на этом этапе?** См. честный разбор в
[`КАК-ЭТО-РАБОТАЕТ.md`](КАК-ЭТО-РАБОТАЕТ.md#что-реально-работает-а-что-имитация) —
на этапе 1 это смена статуса внутри платформы; реальная интеграция с API Национального
каталога запланирована на этап 2.

# Матрица доступа НК-ЛАБ

| Возможность | Администратор | Редактор | Наблюдатель | Оператор НК-ЛАБ |
|---|---:|---:|---:|---:|
| Просмотр каталога, пилотов и обменов | Да | Да | Да | Да |
| Экспорт карточек и отчётов | Да | Да | Да | Да |
| Импорт и профили колонок | Да | Да | Нет | Да |
| Создание и изменение карточек | Да | Да | Нет | Да |
| Валидация и отметка готовности | Да | Да | Нет | Да |
| Управление пилотом и его выборкой | Да | Да | Нет | Да |
| Создание, повтор и сверка обмена НК | Да | Да | Нет | Да |
| Управление пользователями организации | Да | Нет | Нет | Нет |
| Работа с общей очередью оператора | Нет | Нет | Нет | Да |
| Утверждение версий правил | Нет | Нет | Нет | Да |

Роль `client` сохранена для совместимости и равна владельцу организации.
Платформенная роль `admin` включает права оператора; управление командой доступно
ей только при наличии привязки к конкретной организации.

Права проверяются сервером. Скрытие элементов интерфейса для наблюдателя помогает
не предлагать недоступные действия, но не является механизмом безопасности.
